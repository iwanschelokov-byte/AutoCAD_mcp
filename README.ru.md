# AutoCAD MCP Plugin

Автоматизация AutoCAD через **Model Context Protocol (MCP)**. Плагин позволяет Claude и другим ИИ-ассистентам создавать, изменять, запрашивать, искать и визуально проверять чертежи AutoCAD обычными словами.

> «Начерти план этажа с тремя спальнями» — и он чертит.
> «Найди аккумуляторную, ближайшую к санузлу» — и он её находит.
> «Сделай снимок экрана и проверь, правильно ли получилась компоновка» — и он проверяет глазами.

> **Это форк** репозитория [NCO-1986/AutoCAD_mcp](https://github.com/NCO-1986/AutoCAD_mcp).
> Добавлены поддержка AutoCAD 2027 (.NET 10 / R26.0), работающая печать в PDF с обрезкой
> страницы по рамке, шестнадцатеричные дескрипторы объектов, управление документами и
> диагностика командной строки. Изменения предложены автору в
> [PR #4](https://github.com/NCO-1986/AutoCAD_mcp/pull/4); если он их примет, отдельный
> форк станет не нужен.
> [English version](README.md)

## Архитектура

```
┌─────────────┐     stdio      ┌──────────────────┐     TCP socket      ┌──────────────────┐
│   Claude /   │ ──── MCP ────▶ │  Python MCP      │ ── JSON-RPC 2.0 ──▶│  C# Plugin       │
│   AI Client  │◀──────────────│  Server           │◀────────────────── │  (inside AutoCAD) │
└─────────────┘                └──────────────────┘   localhost:8081    └──────────────────┘
                                                                              │
┌──────────────┐                          HTTP / JSON-RPC 2.0                  │
│   Browser    │ ──────────────────────────────────────────────────────────────▶│
│   (web app)  │  POST http://127.0.0.1:8082/jsonrpc  (CORS + Chrome PNA ok)   │
└──────────────┘                                                                │
                                                                       AutoCAD .NET API
```

| Компонент | Язык | Расположение |
|-----------|------|--------------|
| **AutoCADMCPPlugin.dll** | C# | `src/AutoCADMCPPlugin/` |
| **MCP-сервер** | Python | `src/mcp_server/` |
| **Манифест бандла** | XML | `config/AutoCADMCPPlugin.bundle/` |

### Как это работает

Плагин на C# загружается внутрь AutoCAD как надстройка и открывает один и тот же конвейер JSON-RPC сразу **двумя транспортами**:

1. **TCP-сокет на `localhost:8081`** — им пользуется Python-сервер MCP, который отдаёт 79 инструментов через stdio для Claude, Claude Code и Claude Desktop.
2. **HTTP на петлевом интерфейсе `localhost:8082`** — для браузерных приложений, которые не умеют открывать сырые TCP-сокеты: вызов `fetch()` на `http://127.0.0.1:8082/jsonrpc` достаёт до любой команды реестра, заголовки CORS и поддержка Chrome Private Network Access включены сразу.

Оба транспорта проходят через один и тот же `JsonRpcHandler`, поэтому каждая команда реестра (`create_line`, `create_table`, `capture_screenshot` и так далее) вызывается одинаково с любой стороны. Команды передаются в главный UI-поток AutoCAD через `Application.Idle` и `DocumentLock`.

### Потокобезопасность

API .NET у AutoCAD однопоточный. Плагин использует событие `Application.Idle` и `DocumentLock`, чтобы безопасно выполнять команды из потоков обработчика сокета в главном потоке приложения.

## Две команды сверх того, только по JSON-RPC

В реестре команд плагина **80** команд — это 79 инструментов MCP, перечисленных выше, плюс две команды измерения текста. Они доступны по TCP/JSON-RPC и через HTTP, но намеренно не обёрнуты в инструменты MCP: они нужны, чтобы рассчитать ширину столбцов до отрисовки таблицы, и чат-клиенту почти бесполезны. Поэтому `list_methods` возвращает 80, а сервер MCP предоставляет 79.

| Команда | Назначение |
|---------|------------|
| `measure_text` | Габариты одной строки при заданной высоте и стиле. Глифы SHX-шрифтов пропорциональные, поэтому расчёт на стороне JS промахивается; здесь возвращается настоящая ширина, которую отрисует AutoCAD. |
| `measure_texts` | Пакетный вариант — до 2000 строк за одну транзакцию. Удобно, когда нужно разметить много ячеек перед черчением. |

Разобранный пример — в разделе [Подбор ширины столбцов по реальному тексту](#подбор-ширины-столбцов-по-реальному-тексту).

## Поддерживаемые версии AutoCAD

| Версия AutoCAD | Целевая платформа .NET | Версия пакета NuGet |
|----------------|------------------------|---------------------|
| **2022, 2023, 2024** | .NET Framework 4.8 (`net48`) | AutoCAD.NET 24.2.x |
| **2025, 2026** | .NET 8 (`net8.0-windows`) | AutoCAD.NET 25.x |
| **2027** | .NET 10 (`net10.0-windows`) | AutoCAD.NET 26.0.0 |

Цели `net48` и `net8.0-windows` собираются всегда. Цель для 2027 компилируется против того `Newtonsoft.Json`, который поставляется внутри AutoCAD 2027 — чтобы сигнатуры на этапе компиляции и на этапе выполнения совпадали, — и поэтому добавляется в сборку только тогда, когда AutoCAD 2027 установлен на машине сборки. На остальных машинах собираются две старших цели, а не падает вся сборка из-за неразрешимой ссылки. Нестандартный путь установки указывается так: `dotnet build ... -p:AutoCADPath2027="D:\...\AutoCAD 2027"`.

Манифест бандла сам выбирает нужную DLL по серии выпуска AutoCAD (`R24.1`–`R26.0`).

## Установка

### Что нужно заранее

- **AutoCAD 2022–2027** (любая редакция, включая LT с поддержкой .NET)
- **Python 3.10 или новее** — для сервера MCP
- **Windows** — AutoCAD существует только под неё
- **.NET SDK 8.0 или новее** — только если собираете из исходников; для цели AutoCAD 2027 нужен **SDK 10.0**

### Вариант A: установка готового плагина, без средств сборки

**Сначала закройте AutoCAD**, затем выполните:

```bash
cd autocad-plugin
install-prebuilt.bat
```

Скрипт скопирует готовые DLL из `dist/` в `%APPDATA%\Autodesk\ApplicationPlugins\`, и AutoCAD подхватит плагин при следующем запуске.

> **AutoCAD 2027:** в `dist/` сейчас лежат только `net48` и `net8.0-windows`. Скрипт честно об этом сообщает и пропускает папку 2027; для 2027 используйте вариант B и соберите из исходников.

### Вариант B: сборка из исходников

Если установлен .NET SDK:

```bash
cd autocad-plugin
install.bat
```

Скрипт соберёт все цели, доступные на машине, скопирует DLL в `%APPDATA%\Autodesk\ApplicationPlugins\AutoCADMCPPlugin.bundle\`, проверит, что каждая папка платформы действительно получила свою DLL, и AutoCAD подхватит плагин при запуске. В итоговой сводке будет сказано, заполнена папка AutoCAD 2027 или пропущена.

Оба установщика в конце проверяют, импортируются ли `mcp`, `openpyxl` и `pikepdf`, и предлагают доустановить недостающее. Шаг 3 ниже — то же самое, но руками. Проверка ничего не ставит без вашего согласия и молча пропускается, если Python не найден в `PATH`.

### Вариант C: установка вручную

Если скрипты почему-то не работают, всё делается копированием:

1. Скопируйте папку `autocad-plugin/config/AutoCADMCPPlugin.bundle` в:
   ```
   %APPDATA%\Autodesk\ApplicationPlugins\
   ```
   > Подсказка: вставьте `%APPDATA%\Autodesk\ApplicationPlugins` в адресную строку проводника — путь раскроется сам.

2. Скопируйте DLL из `autocad-plugin/dist/net48/` в:
   ```
   %APPDATA%\Autodesk\ApplicationPlugins\AutoCADMCPPlugin.bundle\Contents\net48\
   ```

3. Должна получиться такая структура:
   ```
   %APPDATA%\Autodesk\ApplicationPlugins\
     └── AutoCADMCPPlugin.bundle\
           ├── PackageContents.xml
           └── Contents\
                 └── net48\
                       ├── AutoCADMCPPlugin.dll
                       └── Newtonsoft.Json.dll
   ```
   > Для AutoCAD 2025–2026 дополнительно скопируйте `dist/net8.0-windows/` в `Contents\net8.0-windows\`.
   >
   > Для AutoCAD 2027 папка должна называться `Contents\net10.0-windows\` и содержать `AutoCADMCPPlugin.dll`, `System.Drawing.Common.dll`, `Microsoft.Win32.SystemEvents.dll` и `System.Private.Windows.Core.dll` из `bin/Release/net10.0-windows/`. `Newtonsoft.Json.dll` туда класть **не нужно** — AutoCAD 2027 несёт свою копию, и вторая в бандле её перекроет.

4. Запустите AutoCAD — плагин загрузится сам.

### Шаг 2: запустить сервер внутри AutoCAD

```
Команда: MCPSTART
[MCP] Server started on localhost:8081
```

Остальные команды:
- `MCPSTOP` — остановить сервер
- `MCPSTATUS` — показать число подключений

### Шаг 3: установить сервер MCP

```bash
cd autocad-plugin/src/mcp_server
pip install -r requirements.txt
```

Ставятся `mcp`, `openpyxl` (нужен для `create_table_from_excel`) и `pikepdf` (им `plot_to_pdf` обрезает готовую страницу по напечатанной области — см. [Печать в PDF](#печать-в-pdf)). Строго обязателен только `mcp`; без остальных двух отключается по одной возможности.

### Шаг 4: настроить MCP-клиент

Создайте `.mcp.json` в корне проекта:

```json
{
  "mcpServers": {
    "autocad-mcp": {
      "command": "python",
      "args": ["<полный-путь-до>/autocad-plugin/src/mcp_server/server.py"],
      "env": {
        "AUTOCAD_MCP_HOST": "localhost",
        "AUTOCAD_MCP_PORT": "8081"
      }
    }
  }
}
```

Для **Claude Desktop** добавьте в `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "autocad-mcp": {
      "command": "python",
      "args": ["C:/path/to/autocad-plugin/src/mcp_server/server.py"]
    }
  }
}
```

### Шаг 5: проверить

В Claude Code или Claude Desktop:

> «Начерти окружность в точке (50, 50) радиусом 25»

Или вручную через TCP-сокет:

```python
import socket, json
sock = socket.socket()
sock.connect(('localhost', 8081))
sock.sendall(json.dumps({
    "jsonrpc": "2.0", "method": "system_status", "params": {}, "id": "1"
}).encode() + b"\n")
print(sock.recv(4096).decode())
```

Или через HTTP — так же, как это делают браузерные интеграции:

```bash
curl -s -X POST http://127.0.0.1:8082/jsonrpc \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","method":"system_status","params":{},"id":"1"}'
```

`MCPSTATUS` покажет, что работают оба транспорта.

## Печать в PDF

`plot_to_pdf` печатает либо именованный лист, либо прямоугольную область пространства модели через собственный механизм публикации AutoCAD, поэтому в PDF попадает ровно то, что показал бы предпросмотр печати — со стилями печати, весами линий и всем остальным.

Сложнее всего обычно оказывается формат бумаги. AutoCAD умеет печатать только на тот лист, который определён в устройстве печати, а листы адресуются *каноническими* именами вроде `ISO_full_bleed_A1_(841.00_x_594.00_MM)`, а не локализованными подписями из диалога печати. Что предлагает устройство, показывает `plot_devices`: вызов без аргументов возвращает установленные устройства печати, таблицы стилей печати и форматы бумаги драйвера PDF по умолчанию, а с аргументом `device` (принимается и синоним `plotter` — некоторые хосты MCP перехватывают аргумент с именем `device` до того, как его увидит инструмент) и необязательной подстрокой `filter` список сужается. У каждой записи возвращаются область печати и поля, так что вызывающая сторона отличит лист без полей от листа с рамкой в 5 мм ещё до выбора.

Если оставить `paper` в значении по умолчанию `auto`, всё это не нужно: команда измеряет печатаемую область и берёт наименьший из определённых листов, который её вмещает, предпочитая ту ориентацию, при которой не потребуется поворот, если лист существует в обеих. Наименьший *вмещающий* лист почти никогда не совпадает по размеру с самой областью, поэтому готовая страница затем обрезается по фактическим границам печати, а излишек удаляется; в ответе возвращаются `trimmed`, `trimmed_size_mm` и применённый `trim_box_mm`. Чтобы оставить страницу ровно такой, какой её выдал драйвер, передайте `trim: false`.

Обрезка выполняется в Python-сервере MCP библиотекой [pikepdf](https://pypi.org/project/pikepdf/), которая ставится из `requirements.txt`. Для печати она не обязательна: без неё печать всё равно проходит, а в ответе будет `trimmed: false` и `trim_error` с названием недостающего пакета. Область обрезки измеряется по настоящему `MediaBox` полученного файла, а не по номинальному размеру листа, потому что `DWG To PDF.pc3` квантует страницу примерно по 0,042 мм на единицу, и номинальный лист 841 × 594 мм приходит как 841,022 × 594,078 мм.

Одно требование общее для обеих команд: чертёж должен быть открыт. Устройства печати, таблицы стилей и форматы бумаги читаются через `PlotSettingsValidator.Current`, а `Current` — это «текущий *для активного документа*», и без открытого чертежа читать их просто неоткуда. Обе команды проверяют наличие активного документа до обращения к API печати и возвращают понятную ошибку с объяснением, что делать.

## Вызов из браузера или веб-приложения

HTTP-обёртка делает все 80 команд плагина доступными любому внутреннему инструменту в браузере — без клиента MCP, без Claude в цепочке и без лицензии на каждого инженера. Инженер один раз запускает плагин (`MCPSTART` в AutoCAD), а веб-приложение обращается напрямую к `localhost:8082`.

### Короткий пример: вставка таблицы

```js
async function insertBeamSchedule(beams) {
  const r = await fetch('http://127.0.0.1:8082/jsonrpc', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      jsonrpc: '2.0',
      id: '1',
      method: 'create_table',
      params: {
        position: [0, 0, 0],
        title: 'Beam schedule',
        rows: beams.length,
        columns: 8,
        row_height: 500,
        column_width: 2000,
        layer: 'BEAM_SCHEDULE',
        data: [
          ['Beam ID', 'b×D', 'L (m)', 'Top', 'Bot', 'Stirrups', 'Side-face', 'Status'],
          ...beams.map(b => [b.id, b.section, b.length, b.top, b.bot, b.stirrups, b.sideFace, b.status]),
        ],
      },
    }),
  });
  return r.json();
}
```

### Цветные заливки: полосы заголовков, индикаторы состояния

`create_hatch` и вариант `hatch` внутри `bulk_create` принимают `color` (ACI 0–255) и `true_color` `[r, g, b]` (имеет приоритет над ACI). Для залитых ячеек используйте узор `SOLID` и тот же контур, по которому уже построена сетка, — тогда цвет ляжет *под* текст, нарисованный поверх:

```js
{
  jsonrpc: '2.0', id: '2', method: 'bulk_create',
  params: {
    entities: [
      // тёмно-зелёная полоса строки заголовка, RGB задан точно по фирменному цвету
      {
        type: 'hatch',
        params: {
          boundary: [[0, 0], [12000, 0], [12000, 600], [0, 600]],
          pattern: 'SOLID',
          true_color: [37, 78, 55],
          layer: 'TABLE_HEADER'
        }
      },
      // линии сетки, текст и прочее — рисуются позже, поэтому оказываются сверху
    ]
  }
}
```

Контурной полилинии штриховки присваивается тот же цвет, чтобы она не проступала контрастным контуром `ByLayer` на фоне заливки.

### Подбор ширины столбцов по реальному тексту

Глифы SHX-шрифтов (Romans, Standard, Romantic, RomanD, Italic, Italicc) пропорциональные и подогнаны вручную; приближённый расчёт в пикселях на стороне JS заметно расходится с тем, что нарисует AutoCAD. Браузерный клиент, строящий таблицу, может спросить у AutoCAD настоящие размеры текста до того, как назначит ширину столбцов:

```js
const r = await fetch('http://127.0.0.1:8082/jsonrpc', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    jsonrpc: '2.0', id: '1', method: 'measure_texts',
    params: {
      items: [
        { text: 'BEAM',                 height: 225, style: 'Romans' },
        { text: 'SIZE',                 height: 225, style: 'Romans' },
        { text: 'BOTTOM REINFORCEMENT', height: 225, style: 'Romans' },
        { text: 'GB-400x700',           height: 225, style: 'Romans' },
      ],
    },
  }),
});
// → { results: [{ text, width, height }, ...] }   ширина по настоящим габаритам DBText
```

`measure_text` — вариант для одной строки. Обе команды работают так: во временную транзакцию в пространство модели добавляется пробный `DBText`, у него читаются `GeometricExtents`, после чего транзакция отменяется — в чертёж пользователя проба не попадает. Размер пакета ограничен 2000 элементами за вызов, чтобы сорвавшийся клиент не заблокировал главный поток AutoCAD.

### CORS

По умолчанию слушатель разрешает любой источник (`*`), чтобы внутренние инструменты работали без настройки. **В рабочем контуре укажите свой источник явно** — переменной окружения, заданной до запуска AutoCAD:

```bat
setx AUTOCAD_MCP_HTTP_ORIGINS "https://your-internal-app.example.com"
```

Несколько источников перечисляются через запятую. Заголовок `Access-Control-Allow-Private-Network: true` отправляется всегда, чтобы предварительный запрос Chrome Private Network Access проходил, когда HTTPS-страница обращается к `127.0.0.1`.

### Как отключить HTTP-обёртку

Установите `AUTOCAD_MCP_HTTP_PORT=0` в окружении пользователя — HTTP-слушатель не поднимется вовсе (TCP на 8081 при этом продолжит работать для Claude).

## Удаление

```bash
cd autocad-plugin
uninstall.bat
```

Либо удалите вручную папку `%APPDATA%\Autodesk\ApplicationPlugins\AutoCADMCPPlugin.bundle\`.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `AUTOCAD_MCP_HOST` | `localhost` | Хост TCP-сокета плагина (для Python-сервера MCP) |
| `AUTOCAD_MCP_PORT` | `8081` | Порт TCP-сокета плагина (для Python-сервера MCP) |
| `AUTOCAD_MCP_HTTP_PORT` | `8082` | Порт HTTP-обёртки для браузерных приложений. `0` — отключить. |
| `AUTOCAD_MCP_HTTP_ORIGINS` | `*` | Список разрешённых источников CORS через запятую. В рабочем контуре укажите конкретный (например, `https://pdf.example.com`). |

## Как добавить свою команду

1. Создайте класс, реализующий `ICommand`, в папке `Commands/`
2. `CommandRegistry` найдёт его сам — регистрировать вручную не нужно
3. Добавьте соответствующий инструмент MCP в `server.py`
4. Пересоберите и переустановите: `install.bat`

Пример:

```csharp
public class MyCommand : ICommand
{
    public string MethodName => "my_command";

    public CommandResult Execute(JObject parameters)
    {
        Document doc = Application.DocumentManager.MdiActiveDocument;
        using (EntityHelper.LockDoc())
        using (Transaction tr = doc.Database.TransactionManager.StartTransaction())
        {
            // здесь ваш код на API AutoCAD
            tr.Commit();
        }
        return CommandResult.Ok(new JObject { ["message"] = "Done" });
    }
}
```
